## Goal (user's words, tidied)
Multiple-choice tests for ANY subject (Science, English...): the teacher gives a paper test; for each student the teacher uploads a photo/PDF of the answer sheet, takes a camera photo, or types the circled letters. The computer marks it and counts the mistaken ideas. Students with the same mistaken idea are grouped. The teacher can send that group a practice quiz (AI-drafted, teacher reviews, published only to those students). Each student sees their own result and problem.
